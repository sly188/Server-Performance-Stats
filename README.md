Server Performance Stats

Display comprehensive server performance metrics, written using bash shell

Features: CPU Usage

Memory Monitoring

Disk Analysis

Top 5 Processes

One command Execution





Requirements:

Linux OS

Bash shell

awk, grep, ps, df, bc



can be installed through cloning on GitHub
git clone https://github.com/sly188/Server-Performance-Stats.git

cd Server-Performance-Stats

chmod +x ServerStats.sh



Can be run using the following command line

./ServerStats.sh
